# Design decision tree

1. Is the surface public marketing or authenticated product?
   - Public: use cinematic evidence studio, proof-first composition, premium visual energy.
   - Product: use Studio Instrument, restrained density, exact state and familiar controls.
2. Does the claim involve performance, neurology, scoring or virality?
   - If not implemented and evidenced in V0, do not claim it as shipped.
   - If future-compatible, label as design support or future analytical surface.
3. Is an action paid, publishing, scheduling, approval, consent or destructive?
   - Use explicit confirmation, no optimistic state, exact object/version/account/cost.
4. Is a status unknown?
   - Preserve unknown as its own state; never render as success or failure.
5. Is a reference pattern copied?
   - Copy visual language only unless license and canonical copy authority allow more.
   - Preserve attribution and isolate templates.
