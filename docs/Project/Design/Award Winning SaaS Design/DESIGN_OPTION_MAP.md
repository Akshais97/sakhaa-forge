# Design option map

## Landing options

- Friendly light SaaS: accessible, approachable, weaker premium differentiation.
- Dark cinematic evidence lab: strongest fit for video, proof and creative intelligence.
- Editorial Open Design: strong template mechanics, weaker direct product fit.

Decision: dark cinematic evidence lab with friendly real-estate clarity.

## App options

- Dashboard-first: fast comprehension, risks decorative metrics.
- Workflow-first: maps V0 journey, may get long.
- Evidence-first studio: balances workflow, media and proof.

Decision: evidence-first studio.

## Component options

- Candidate cards: selected for viral discovery and script variants.
- Dense tables: selected for ledger, lineage, performance and audit.
- Stage spine: selected for asynchronous blueprint/generation/publish flows.
- Giant metric tiles: limited to landing visuals only when evidence-backed.
