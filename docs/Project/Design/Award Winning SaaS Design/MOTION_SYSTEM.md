# Motion system

## Timing

- App transitions: 150-250ms.
- Landing staged reveals: 300-700ms when content remains visible by default.
- No bounce or elastic easing.

## Motion roles

- State: queued, running, retrying, unknown, verified.
- Sequence: blueprint stages, script selection, provider operation, publish verification.
- Media: preview playback, timeline scrub, captions and shot cards.
- Focus: inspector open, modal confirm, error summary.

## Reduced motion

All animated states need a reduced-motion equivalent that keeps labels, status and progress legible.
