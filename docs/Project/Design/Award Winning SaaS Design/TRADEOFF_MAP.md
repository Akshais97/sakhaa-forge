# Tradeoff map

| Choice | Upside | Risk | Guardrail |
|---|---|---|---|
| Dark landing | Premium, video-native | Can look like generic AI tool | Use real product proof, not neon decoration |
| Glass layers | Depth and modernity | Low contrast, cliche | Use only around hero composites |
| Strong motion | Communicates pipeline | Distracts product users | App motion only for state |
| Scores and markers | Shows intelligence | Can imply prediction | Show source, confidence, limits |
| Dense app UI | Operational efficiency | Cognitive load | Progressive disclosure and right inspector |
| Real-estate specificity | Clear buyer fit | Narrower market | Correct for V0 target |
