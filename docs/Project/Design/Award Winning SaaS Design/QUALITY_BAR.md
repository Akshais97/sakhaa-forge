# Quality bar

## Landing page

- Product signal appears in first viewport.
- Hero uses credible product/media evidence, not decorative abstraction.
- Copy follows claim boundaries.
- Responsive at mobile, tablet and desktop.
- No horizontal overflow.
- Contrast passes AA.
- Visual system is not generic AI SaaS.

## App UI

- Every screen exposes loading, empty, failure, retry and recovery states.
- Status labels match backend truth.
- Paid and publishing flows show exact cost/account/version and wait for server confirmation.
- Evidence, lineage and hashes are accessible without leaking secrets.
- Reviewer/Owner/Admin/Client Manager permissions remain visually and server-side consistent.
