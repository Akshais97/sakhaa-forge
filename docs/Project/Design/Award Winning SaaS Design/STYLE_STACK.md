# Style stack

## Base

- Studio Instrument from `docs/Project/DESIGN.md`.
- Dark-mode-first for landing and media-heavy app surfaces.
- Light mode support for dense admin/forms.

## Style usage

- Swiss/International: grid, typography, alignment.
- Modernist: functional beauty, restrained hierarchy.
- Luxury Minimal: premium quietness.
- Corporate Professional: trust and governance.
- Tech Forward: product composites and workflow diagrams.
- Art Deco/Neo-Geo: fine linework, geometric markers.
- Glassmorphism: limited depth on hero composites.
- Gradient Modern: controlled accent transitions.
- Kinetic: timeline, stage and video motion.
- Calm/Scandinavian: spacing and breathing room.
- Neumorphic/Skeuomorphic: high-value media objects only.

## Rejected defaults

- Generic purple-blue gradients.
- Beige/paper as dominant body background.
- Repeated metric-card hero template.
- Decorative orbs/blobs as a primary background device.
- Gradient text.
