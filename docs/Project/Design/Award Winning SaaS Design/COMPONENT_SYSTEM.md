# Component system

## Foundations

- Semantic tokens only.
- Status mapping generated from backend status authority.
- One component per concept.
- Story/state coverage required before implementation.

## Signature components

- Evidence-backed brand profile.
- Viral candidate card.
- Rights warning banner.
- Cinematic timeline.
- Stage spine.
- Script comparison matrix.
- Scorecard with limitations.
- Neurology marker panel with confidence.
- Real-user feedback layer.
- Credit estimate and ledger.
- Provider operation state.
- Review approval binder.
- Publication verification checklist.
- Lineage graph.

## Component requirements

Every component must define loading, empty, error, blocked, stale, unknown and reduced-motion states where applicable.
