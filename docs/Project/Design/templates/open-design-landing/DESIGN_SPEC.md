# Open Design landing template design spec

Source: `https://github.com/nexu-io/open-design/tree/main/plugins/_official/examples/open-design-landing` and the existing local template files.

## Extracted design language

- Editorial single-page landing system.
- Warm paper/editorial aesthetic in the source skill, with collage assets and scroll reveal.
- Local template includes self-contained HTML preview, plugin metadata, a skill contract and generated image assets.
- Strong recipe structure: brand inputs, navigation, hero, about, capabilities, labs, method, work, testimonial, CTA and footer.

## Useful for Sakhaa Forge

- Template discipline: content inputs and visual assets are explicit.
- Separate template folder prevents accidental product-code adoption.
- Asset manifest and prompt notes make generated images inspectable.
- Verification checklist can inspire future landing QA.

## Adaptation rules

- Do not reuse Open Design text or IA as Sakhaa Forge copy.
- Do not use the editorial collage lane as the default Sakhaa Forge identity.
- Reuse only the idea of typed sections, self-contained artifact previews, asset manifests and attribution.
- Sakhaa Forge landing must remain evidence-first, real-estate-specific and V0-claim-safe.
