# open design landing

This is a separate design template reference, not a Sakhaa Forge app implementation.

## Template contract

- Keep source files isolated in this folder.
- Use the template only as reference for landing-page structure, asset manifest discipline, scroll-reveal checks and generated visual workflow.
- Any future product use must be re-specified through Sakhaa Forge design docs and canonical V0 language.

## Useful section patterns

- Hero with strong product signal and one primary CTA.
- Capability cards with visual proof.
- Method/process sequence where order matters.
- Work/proof section for concrete examples.
- Closing CTA with a single conversion action.

## Sakhaa Forge adaptation

Replace editorial collage content with:

- approved brand profile evidence;
- viral candidate source card;
- 9:16 video preview;
- lineage trail;
- credit estimate and reservation state;
- review and audience verification checklist.
