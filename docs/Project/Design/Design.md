# Design compatibility note

`docs/Project/DESIGN.md` is the authoritative design system for the landing page,
authenticated application, generated overlays, component states, tokens and accessibility.

Use this file only as a compatibility pointer for references that expect a design document
inside `docs/Project/Design/`. Do not treat it as a second source of truth.

For implementation, read:

1. `../DESIGN.md`
2. `PROJECT_DESIGN_INDEX.md`
3. `PROJECT_BRAND_GUIDELINES.md`
4. `PROJECT_CONTENT_AND_LANGUAGE_GUIDE.md`
5. `DESIGN_colors.md`

The files in `references for only design and not TEXT/` are visual references only. They
may inform spacing, contrast, rhythm, motion and component density. Do not copy their text,
claims, labels, information architecture, product promises or unsupported behaviours.
