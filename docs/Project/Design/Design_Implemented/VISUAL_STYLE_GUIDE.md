# Visual style guide

## Style stack

- Base: Studio Instrument from `DESIGN.md`.
- Landing: premium dark-mode-first SaaS with cinematic proof objects.
- App: restrained system-of-record UI.

## Colour

- Use `DESIGN.md` primitives and semantic tokens as authority.
- Iris: primary interactive and focus colour.
- Ember: single creative-forward accent per view.
- Status palette: semantic state only, never decoration.
- Avoid one-note purple/blue gradients and beige/cream saturation.

## Type

- Product UI uses compact, readable sans. Mono only for IDs, hashes, money, timestamps and exact evidence labels.
- Landing display type can be more distinctive, but must avoid cramped `-0.05em` to `-0.08em` letter spacing observed in references.

## Imagery

- Product composites should show 9:16 media, timeline, evidence, source cards and verification states.
- Use real or generated raster imagery for landing hero and campaign proof when implementation begins.
- Do not substitute decorative blobs for product proof.

## Premium cues

- Precision grid, strong contrast, exact linework, tabular numbers, restrained motion, tactile media objects, content hashes, timestamps and clear state markers.
