# Motion and interaction

## Motion principles

- Motion communicates state, sequence or media-native timing.
- Product UI transitions target 150-250ms.
- Landing page can use larger staged motion, but content must be visible by default before reveal scripts run.
- Reduced motion must remove movement without hiding content.

## Approved motion patterns

- Stage spine progress between workflow nodes.
- 9:16 preview playback and timeline scrub.
- Meter fills only when backed by real state or retained evidence.
- Evidence inspector slide-in.
- Verification checklist transitions.
- Upload/generation/reconciliation job status transitions.

## Limited patterns

- Glass blur, scanlines, floating phone/product objects and animated grids are limited to landing hero or media lab moments.
- No bouncing, elastic easing, decorative infinite motion or fake progress percentages.

## Interaction rules

- Critical actions require server confirmation before success state.
- Hover-only controls must have keyboard-visible equivalents.
- Dialogues name the exact object/version/account/cost affected.
- Sliders are only for reversible configuration, not irreversible paid or publishing decisions.
