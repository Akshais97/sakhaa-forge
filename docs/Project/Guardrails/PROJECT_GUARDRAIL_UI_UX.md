# UI/UX Revamp Guardrails

- Keep four outcomes distinct; never replace them with one decorative score.
- Put confidence and proxy limitations adjacent to evidence.
- Preserve the user's selected objective throughout navigation.
- Show before/after deltas and secondary regressions.
- Never hide failed stages behind an endless spinner.
- Do not use brain imagery to imply individual mind-reading.
- Avoid neon “neuroscience” theatrics, unexplained radar charts, and excessive gradients.
- Recommendations must link back to factors and clusters.
- Require confirmation before submitting a cost-authorized V0 brief or destructive deletion.
- Provide keyboard navigation, visible focus, AA contrast, text alternatives, and tables
  for all charts.
- Optimize dense comparison for desktop while keeping mobile review usable.
- User testing must include a client manager and reviewer before release.
